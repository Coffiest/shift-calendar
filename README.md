# shift-calendar

調整さんのような手軽さで使う、アルバイトのシフト調整ツール。

## 使い方

1. 店長がトップページで「お店を作る」(店名とパスワード)。
2. 店長の画面で募集する月を作り、「バイトに送るリンク」を送る(リンクは毎月同じ)。
3. バイトはリンクを開き、名前を入れて休みたい日を押すだけ。自分の名前を押せば後から直せる。
4. 店長の画面に、日ごとの出勤できる全員の名前が入る。名前を押すとその日は「出勤なし」、もう一度押すと戻る。
   人数の色: 0人=濃い赤 / 1人=薄い赤 / 2〜4人=色なし / 5人=薄い青 / 6人以上=濃い青。
5. 「受付を終了する」で締め切り、「PNGで書き出す」で完成したカレンダーを画像にする。

## 仕組み

- Next.js(App Router)+ Postgres(本番は Neon)。表は最初のアクセスで自動で作られる。
- 環境変数: `DATABASE_URL`(必須)、`SESSION_SECRET`(任意)。
- 祝日は `@holiday-jp/holiday_jp`(2050年まで収録)。

## 手元で動かす

```
npm install
DATABASE_URL=postgres://user:pass@localhost:5432/shift npm run dev
```
